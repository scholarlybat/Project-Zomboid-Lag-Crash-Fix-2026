# Project Zomboid Lag & Crash Fix v1.0.0

## Release Overview
First public release of **Project Zomboid Lag & Crash Fix** — a lightweight Windows utility focused on improving startup reliability, reducing common crashes, and smoothing out gameplay-related stability issues.

## Key Features
- Crash repair workflow
- Launch optimization
- Lag reduction and FPS stabilization
- Memory and cache cleanup
- Mod conflict checking guidance
- Windows 10 / Windows 11 support

## Recommended Use
Run the tool when Project Zomboid:
- crashes on launch;
- shows a black screen;
- stutters heavily;
- fails to start after updates;
- becomes unstable after config or mod changes.
